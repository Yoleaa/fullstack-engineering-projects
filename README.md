# 400 Full-Stack Engineering Projects

A learning portfolio built around *RESTful Web Services* (Richardson and Ruby) and 16 complementary books.
Every project turns book knowledge into working, tested, documented code.

## Two tracks
- **Core 72**: the depth-first plan to follow (see `00-programme/core-72.md`).
- **400-project bank**: the full curriculum, used for extra practice (see `00-programme/curriculum.md`).
- **Portfolio**: about 20 polished flagship projects.

## Where to start
1. Read `00-programme/engineering-standard.md`.
2. Open `01-web-foundations/project-001/README.md` and build Project 001.
3. Tick projects off in `00-programme/project-register.md` and log each week in `00-programme/learning-progress.md`.

## Project rule
No project is complete until it has requirements, design, working code, tests, a README, and (where it makes sense) a deployment.

Success is measured by how many projects you can explain, test, maintain and deploy, not by how many you start.
