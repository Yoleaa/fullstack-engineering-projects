# Design decisions (Project 001)

## ADR-001: Palette, fonts and layout
- **Context:** One-page profile for a telecommunications engineer moving into web development.
- **Decision:** Dark slate header, cool white page, one blue accent (`#0b5fa5`); system fonts only (no downloads, fast on slow connections); a blue left border on sections, like a cable run on a plan.
- **Consequences:** Very fast to load and easy to maintain. Fonts will vary slightly between devices.
